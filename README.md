# AI Portfolio

Public AIGC portfolio and blog for `www.matianle.com`.

## Local development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env` and point `VITE_API_BASE_URL` to the API.

## Vercel

- Build command: `npm run build`
- Output directory: `dist`
- Environment: `VITE_API_BASE_URL=https://api.matianle.com`
- Domain: `www.matianle.com`
